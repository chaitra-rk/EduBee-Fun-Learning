# 🐝 EduBee – Fun Learning Website for Kids & Teens

**Learning Made Fun, One Buzz at a Time!**

## 📖 About the Project

EduBee is an AI-assisted UI/UX design project created using **Figma Make**. It is a conceptual educational platform designed to make learning fun, interactive, and personalized for children and teenagers.

The project explores AI-powered learning, gamification, smart study planning, progress tracking, and parental involvement through a colorful and user-friendly interface.

## 🎯 Objectives
- Make learning interactive and enjoyable.
- Explore personalized AI-powered learning experiences.
- Encourage consistent study habits through rewards and streaks.
- Simplify academic planning.
- Help parents monitor learning progress.
- Promote healthy digital habits.

## ✨ Key Features

**📚 AI-Powered Learning**
- AI-generated worksheets and quizzes.
- Interactive flashcards and memory games.
- Easy, Medium and Hard difficulty levels.

**🎮 Gamified Learning**
- Daily study streaks.
- Points, badges and achievements.
- Interactive learning activities.

**📅 Smart Timetable**
- Personalized study schedules.
- Subject and activity management.
- Study sessions and break reminders.

**👨‍👩‍👧 Parent Dashboard**
- Academic progress monitoring.
- Goal setting and rewards.
- Learning reports and screen-time preferences.

**🌱 Healthy Habits**
- Water and nutrition reminders.
- Exercise and eye-rest notifications.
- Light and dark themes.
